Other files in `archive/` are superseded collection, source, feature and training plans. They are historical records, not active instructions. Source collection and the old supervised runner are not required for the RL demonstration. Executable files stay at their original paths where tests or frozen artifacts depend on them.

Published figures contain aggregate metrics only. Local datasets, model weights, credentials, browser profiles, source exports and account prediction tables remain Git-ignored. See the root [current status](../STATUS.md) and [project scope](../PROJECT_PLAN.md).
